Pilih salah satu dari lima contoh, atau masukkan nama perusahaan dan tabel layanan. Segmen dipilih secara eksplisit untuk mengurangi salah identitas.

02

Temukan informasi publik

Google hanya menerima nama dan segmen perusahaan. Aplikasi membaca maksimal lima hasil dan halaman publik yang bisa diakses. CAPTCHA tidak dilewati; kegagalan akses ditampilkan.

03

Analisis dengan Ollama lokal

Data pelanggan dan kutipan sumber dikirim ke Ollama pada mesin yang sama, bukan ke layanan LLM cloud. Model menyusun aktivitas dan peluang; klaim tanpa kutipan valid ditandai hipotesis.

04

Tinjau diagram & konfirmasi

Diagram mengikuti ecosystem IVCA pada materi: 4 support, 5 primary activities, dan empat sisi ekosistem. Gunakan pertanyaan discovery sebelum menawarkan solusi.

Menjalankan model lokal

Pasang Ollama dari sumber resminya, lalu jalankan di terminal pada mesin aplikasi:

ollama serve
# Terminal lain:
ollama pull qwen2.5:3b

Jika memakai model lain, atur OLLAMA_MODEL saat menyalakan aplikasi. Untuk cloud ini, domain www.google.com, registry.ollama.ai, ollama.com dan host unduhan model perlu diizinkan melalui pengaturan lingkungan. scripts/setup-ollama.sh menyediakan pemasangan lokal dengan checksum.

Scraping menggunakan HTML dan Chromium untuk halaman yang memerlukan JavaScript. Jika Google meminta CAPTCHA, proses dihentikan. Tunggu akses Google pulih lalu jalankan kembali; tidak ada API pencarian berbayar yang digunakan.

Batas interpretasi

“Existing” berasal dari tabel pelanggan. “Prospect” adalah hipotesis peluang. Status “Win”, nilai wallet share, dan kondisi operasional tidak ditetapkan tanpa bukti. Pemetaan produk pada diagram merupakan usulan untuk dikonfirmasi.
