# Contoh output IVCA

**Cara paling mudah:** [buka PDF berisi lima diagram](Contoh-Diagram-5-Perusahaan.pdf).

**Pembaruan produk resmi:** [contoh diagram solusi dan tautan sumber produk](Contoh-Matching-Produk-Resmi.pdf). Nama produk dicocokkan dengan snapshot 72 entri Telkom Solution/IndiBiz yang dibaca pada 27 Oktober 2026. Pemetaan kebutuhan perusahaan tetap hipotesis, bukan hasil riset Google atau inferensi LLM. Aplikasi lengkap menyediakan tab **Katalog resmi** untuk pembaruan dan **Peluang solusi** untuk rincian pencocokan.

Untuk mencoba antarmuka tanpa terminal, unduh [Rantai-Buka-Langsung.html](Rantai-Buka-Langsung.html), lalu buka file itu dengan Chrome atau Edge. Pilih contoh pelanggan, ubah data bila perlu, dan klik **Perbarui diagram contoh**. File ini tidak membutuhkan Python, server, instalasi, atau internet. Ia menggunakan kerangka sektor yang sudah disertakan; tidak mengakses Google atau LLM dan tidak menyimpan data setelah tab ditutup.

Lima SVG berikut dibuat menggunakan fitur ekspor aplikasi. Setiap diagram memuat nama perusahaan dan mengikuti struktur ecosystem IVCA materi PDF. **Semua adalah kerangka hipotesis sektor, belum hasil scraping Google atau LLM.**
